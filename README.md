# Tic Tac Toe 2.0

Ultimate Tic Tac Toe em português europeu, com visual neon, dois jogadores locais e CPU com três dificuldades. Inclui desfazer, placar da sessão e interface responsiva.

Joga em https://yvllima.github.io/tic-tac-toe-2/ ou abre `index.html` no browser. HTML, CSS e JavaScript puro, sem dependências e sem armazenamento persistente.

A célula escolhida determina o próximo mini-tabuleiro. Conquista três mini-tabuleiros em linha para vencer!
